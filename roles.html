Job roles and responsibilities

Related roles share a foundation but differ in focus.

Role Main focus Typical responsibilities How it differs
Help Desk Technician Supporting users Tickets, password resets, basic fixes Works directly with users; rarely changes servers.
System Administrator Keeping systems running Servers, patches, backups, accounts Responsible for uptime and security of existing systems.
Systems Engineer Designing and building Architecture, automation, cloud migration Plans new systems instead of only maintaining current ones.
Network Administrator Connectivity Routers, switches, firewalls, VPNs Concentrates on the network rather than servers.
IT Infrastructure Manager Leading and planning Budget, staff, vendors, strategy Manages people and priorities more than technical tasks.

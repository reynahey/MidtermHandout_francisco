Required skills and tools

The skills and tools that prepare you for a System Administrator career.

Skills to prepare

Active Directory management

Controls who can access what across a Windows network.

Linux command line

Manages most servers and cloud systems efficiently.

Backup and recovery

Protects data and restores service after failure.

System monitoring

Spots performance problems before users notice them.

Documentation

Records procedures so teams can repeat and audit work.

Tools and technologies

PowerShell and Bash

Scripting languages for automating Windows and Linux tasks.

VMware / VirtualBox / Hyper-V

Virtualization platforms for building safe practice labs.

Active Directory

Directory service for users, computers and policies.

Zabbix / Nagios

Monitoring tools that track server health and send alerts.

AWS / Microsoft Azure

Cloud platforms used to host and scale servers.

Git

Version control for scripts and configuration files.
